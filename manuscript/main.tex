\section*{Data Availability}
The lunar crustal magnetic field datasets analyzed in this study are available through the NASA Planetary Data System (PDS) Planetary Plasma Interactions (PPI) Node under DOIs \href{https://doi.org/10.17189/1520494}{10.17189/1520494} and \href{https://doi.org/10.17189/rk57-g992}{10.17189/rk57-g992}. Processed landing site tables, systematic review datasets, and interactive 3D visualization assets are archived in the Zenodo repository (\href{https://doi.org/10.5281/zenodo.XXXXXXX}{DOI: 10.5281/zenodo.XXXXXXX}) and hosted on GitHub (\url{https://github.com/dr-richard-barker/lunar-magnetic-biology}).

\section*{Code Availability}
All Python scripts, processing pipelines, figure generation modules, and web visualization source code are open source under the MIT license and available at \url{https://github.com/dr-richard-barker/lunar-magnetic-biology}.
