# Data Directory

This directory contains all data used in the analysis.

## `raw/` — Original Data

Downloaded from the NASA Planetary Data System (PDS). These files are **not** tracked in version control due to size. Run `make download` or `python scripts/01_download_data.py` to fetch them.

### Files

| File | Description | Source DOI |
|------|-------------|------------|
| `Bm_30km_65S65N_0E360E.tab` | Lunar crustal magnetic field grid at 30 km altitude, 65°S–65°N | [10.17189/1520494](https://doi.org/10.17189/1520494) |
| `Bm_30km_65S65N_0E360E.xml` | PDS4 XML label (column definitions) | same |
| `polar_maps/*.tab` | North and south polar magnetic field maps at 20 & 30 km | [10.17189/rk57-g992](https://doi.org/10.17189/rk57-g992) |

### Column Format (Equatorial Map)

| Column | Description | Units |
|--------|-------------|-------|
| Latitude | Selenographic latitude | degrees |
| Longitude | Selenographic longitude (0–360°E) | degrees |
| Br | Radial component of magnetic field | nT |
| Bθ | Theta (latitudinal) component | nT |
| Bφ | Phi (longitudinal) component | nT |
| \|B\| | Total magnetic field magnitude | nT |

## `processed/` — Derived Data

Generated by the analysis pipeline. These files **are** tracked in version control for reproducibility.

| File | Description | Generated By |
|------|-------------|--------------|
| `lunar_mag_field_grid.csv` | Merged equatorial + polar magnetic field grid | `02_process_magnetic_data.py` |
| `landing_sites_magnetic.csv` | Landing site coordinates with local field values | `03_identify_landing_sites.py` |
| `biology_literature_summary.csv` | Systematic review of HMF biological effects | `05_generate_tables.py` |

## Data Provenance

All raw data are sourced from the NASA Planetary Data System under US Public Domain license. Processing scripts are fully documented and deterministic — running the pipeline on the raw data will reproduce the processed outputs exactly.
